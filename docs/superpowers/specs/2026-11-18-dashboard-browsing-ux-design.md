# 管理面板浏览体验优化设计

## 意图

HostPilot 是本地使用的 Agent Harness 管理界面。随着会话、工具、Skill 和 Trace 增加，用户需要减少页面滚动，在更宽的桌面空间中快速定位项目记录与配置；手机和窄屏仍需保持可读、可操作。

## 目标

- 让会增长的列表有搜索、分类、分页或限定高度的浏览方式，不再把所有内容连续铺在整页上。
- 让新增、导入、配置等动作位置明确，避免模式选择与新增操作看起来重复。
- 放宽桌面管理面板的内容宽度，并在窄屏下收敛为单列布局。
- 让 Harness 配置按主题折叠，以便后续增加配置项时不持续增加默认页面高度。
- 保留现有 Vue、原生 CSS、Fetch 和 API 契约，不添加界面或路由依赖。

## 非目标

- 不更换本机系统目录选择器；它由操作系统呈现，网页只能改善入口、路径状态和选择后的反馈。
- 不重做后端数据模型或连接协议。
- 不改变工具调用、审批、Skill 执行或 Harness 配置语义。
- 不把每一条长内容强行限制为窄栏；说明性文本保持可读行长，列表和表格使用可用空间。

## 方案

1. **仅增宽页面并整理按钮**：改动最少，但记录和配置仍然形成很长的页面。
2. **所有列表统一分页**：每页较短，但会话列表频繁翻页，工作上下文容易中断。
3. **按内容选择浏览方式（采用）**：会话用固定区域、搜索和时间分组；工具与 Skill 使用分类、搜索和分页；Trace 使用分页列表与独立详情区域；Harness 使用主题折叠；MCP 编辑器按需展开。此方案兼顾高频浏览、长列表和设置页的不同用途。

## 交互设计

### 聊天工作区

- 会话列表提供标题搜索和“今天 / 昨天 / 更早”时间分组；列表区域限定高度并在内部滚动，显示总数或匹配数量。
- 桌面端保留工作区侧栏，窄屏端让会话列表变为有限高度的纵向列表，避免会话无限横向延伸。
- 当前工作区路径及只读状态在标题附近作为清晰状态展示；“更换目录”作为与新建会话分离的次级操作。选择后明确显示结果或错误。
- 文件夹选择仍调用原生系统对话框；不模拟或重绘操作系统控件。

### 工具目录

- 提供名称/说明搜索、工具类型分类和状态筛选。
- 结果按固定页大小分页；页码、结果数和空结果状态清晰可见。
- 工具卡片描述最多显示 3 行；保留全文，桌面悬停显示全文，触屏端可展开/收起。

### Skill 库

- 将“刷新目录”和“导入 ZIP”组合成一个明确的页面操作区：导入作为主操作，刷新为次级操作；窄屏下操作区换行。
- 提供 Skill 搜索和按来源、启用状态筛选，再对结果分页。
- Skill 详情继续按需加载；分页切换时关闭不属于当前结果页的详情，避免详情引用错位。
- Skill 卡片描述限制为最多 3 行；保留完整文本，桌面悬停可查看全文，触屏端提供展开/收起全文入口。

### MCP 连接

- “添加 Server”打开新增编辑器；已有 Server 通过“编辑”打开同一编辑器。
- 配置编辑器内再选择“表单配置”或“JSON 导入”，标题和按钮文案直接说明动作。默认列表视图不常驻空表单。
- 提交成功后收起编辑器并保留成功反馈；取消或关闭时不意外丢弃已编辑内容（如需关闭未保存内容，需有明确确认或保留草稿行为）。
- 用户配置的 Server 增加可编辑用途说明，最多 500 字；标准 JSON 导入不包含该字段时显示待补充状态，编辑后可填写。内置和环境变量管理的 Server 不提供连接配置编辑，显示系统说明。

### Trace 观测

- Trace 列表增加搜索/状态筛选和分页；继续使用现有最近记录 API 上限，不增加后端分页协议。
- 列表和详情在桌面端分栏显示，各自有合理的最大高度；窄屏下改为列表与详情顺序排列，页面主滚动保持可预测。
- 翻页后保留当前选中记录（若仍在结果中），否则清空详情并显示明确选择状态。

### Harness 配置

- 将现有配置组折叠为主题面板，首个常用分组默认展开，其余默认收起；用户可独立展开需要的分组。
- 每组标题和简短说明保持可见，分组新增时仍遵循同一模式。
- 保留现有统一保存流程、校验和成功/错误反馈。

## 全局布局与响应式

- 管理类页面使用统一的宽内容容器，桌面最大宽度从当前 960–1120px 范围提高到约 1240–1320px；窄视口通过弹性宽度和内边距适配。
- 聊天对话正文和说明文字仍限制行长；目录卡片、列表和 Trace 分栏可利用更宽空间。
- 在 760px 左右转为单列；在 560px 左右收紧卡片间距、标题区和操作区，不出现横向溢出。

## 无障碍与反馈

- 搜索和筛选提供可访问标签；分页使用明确的上一页/下一页名称、禁用状态和当前页语义。
- 列表刷新、搜索结果、导入/保存结果继续使用状态播报；无匹配结果说明如何清除筛选。
- 键盘焦点保持可见；触控目标至少 44px。
- 长名称和路径允许换行或省略并提供完整值提示，不破坏卡片网格。
- 工具和 Skill 描述限制只影响视觉展示，不删改后端原始描述；展开全文同时支持触屏和键盘。

## 技术约束与实现边界

- Vue 3 Composition API；派生筛选结果和分页数据使用 `computed`。
- 不添加依赖，不引入 Vue Router 或状态管理库。
- 会话、工具和 Skill 继续使用现有目录 API 返回的数据，在前端搜索/分类/分页；Trace 使用现有最多 500 条的查询上限，前端分页显示最近记录。
- MCP Server 用途说明作为非敏感配置元数据纳入 MCP 配置 API 与 SQLite 持久化；旧数据库迁移后为空字符串，旧客户端未提交该字段时继续兼容。内置/环境变量管理 Server 使用系统提供的说明，不暴露或改变其连接配置。
- 页面设计保持现有 HostPilot 绿色视觉主题和安全提示风格。

## 验收结果

- 大量会话、工具、Skill 或 Trace 时，页面主体不会仅因列表增长而无限延长；用户能通过搜索/分类/页码找到目标内容。
- MCP 默认页面只显示连接列表和清楚的添加入口；新增、编辑和 JSON 导入的关系易理解。
- Skill 页面刷新和导入动作成组、主次分明。
- 工具和 Skill 描述卡片默认高度受限；鼠标悬停、键盘焦点和触屏展开都能阅读完整描述。
- 每个用户管理的 MCP Server 都能填写并保存用途说明；预置/环境变量管理 Server 有明确的系统说明。
- Harness 后续增加配置仍可按分组折叠浏览。
- 1280px 及以上桌面视口能利用更多横向空间；760px 以下布局转为适合窄屏的单列，无横向滚动。
- 现有安全边界和 API 行为保持不变。
