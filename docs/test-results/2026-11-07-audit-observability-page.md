# Audit 观测页面

## 实现范围

- 新增 Audit 前端 API 客户端，查询后端 `/api/v1/observability/audit`。
- 新增只读 Audit 页面，展示时间、操作、结果、资源、原因码和 Trace ID。
- 页面支持 Trace ID、开始时间和结束时间筛选；日期时间按浏览器本地时区转换为带时区的 ISO 时间，单次最多请求 500 条。
- 主导航和跨页面验收流程已加入 Audit 页面入口。

## 安全和边界

- 页面只展示 AuditEvent 允许的有限字段，不提供修改或删除审计记录的操作。
- 暂无 CSV/JSON 导出和自动刷新功能。

## 验证

- Vue TypeScript 类型检查通过。
