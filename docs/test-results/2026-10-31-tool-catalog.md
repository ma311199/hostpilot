# 本地工具目录页面验证

- 日期：2026-10-31
- 范围：只读工具目录 API、Vue 工具页、配置/审批状态和凭证保护

## 实现结果

- `GET /api/v1/tools` 从后端实际 `ToolRegistry` 返回工具名、说明、类型、配置状态、高影响标记和审批要求。
- 工具目录不返回工具参数 schema、handler、RAG 用户 ID 或密钥。
- 页面新增“工具”导航入口，显示当前模型运行时状态、各工具是否配置、写文件审批要求，并支持手动刷新。
- RAG 工具配置状态使用后端本地配置判断；未配置 RAG 时显示未配置。写文件标示为高影响且每次执行前需审批。
