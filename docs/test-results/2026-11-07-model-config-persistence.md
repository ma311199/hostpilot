# 2026-11-07 模型配置持久化验证

## 范围

- 模型名称、Base URL 和流式选项写入本地 SQLite 独立配置表。
- SQLite 模型配置存储接口不接受或保存 API Key。
- 新应用实例读取已保存模型参数后报告需要重新输入 API Key，且状态响应不包含密钥。
- 模型设置页面恢复参数、保持 API Key 输入为空，并允许只补交密钥。
- Provider 创建或非敏感配置写入失败时，不替换当前运行时；候选 Provider 会关闭。
