- 日期：2026-10-31

## 实现结果

- 提案范围为会话摘要或跨会话长期记忆；会话摘要必须绑定有效 UUID，长期记忆不能携带会话 ID。
- 写入服务要求调用方明确传入 `user_approved=True`。该批准只能来自用户确认流程，模型生成的提案本身不构成批准。
- 会话摘要写入前确认目标会话存在；所有范围都受 Markdown 存储大小限制。
- 提案表示目标文件的完整替换内容。提案文本仍是不可信参考数据，不会获得工具授权或系统指令地位。
- 当前只交付应用层契约和服务；HTTP 提案/审批接口、待审批项持久化和模型自动提出记忆更新尚未接入。

## 验证范围

- 未批准提案被拒绝且不写文件。
- 不存在的会话目标被拒绝且不写文件。
- 已批准的会话摘要和长期记忆分别写入对应文件。
- 不匹配的范围字段及超出大小限制的提案被拒绝。
- 单元测试：新增 4 项，随项目完整质量检查一并运行。
