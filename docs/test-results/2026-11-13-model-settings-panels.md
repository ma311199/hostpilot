# 模型配置面板分角色配置与连接测试

- 日期：2026-11-13
- 范围：模型配置 UI、独立保存 API 流程、主模型/轻量模型/Embedding/Reranker 的连接测试接口
- 验证环境：本地单元测试与生产构建；真实模型服务连通性尚未通过新面板逐角色手动复核

## 实现

- 配置面板拆为四个独立可展开的模型角色卡片，每个卡片单独显示状态、输入字段、连接测试和保存按钮。
- 保存某个可选模型角色只提交该角色字段，其他已保存角色不会被覆盖。主 LLM 单独保存。
- 连接测试使用用户当前输入的草稿模型名、Base URL、API Key；若 Key 输入留空，则使用该角色目前可用的凭证。测试请求不会保存配置。
- LLM/轻量 LLM 测试发送短文本请求，Embedding 测试发送一个固定短文本，Reranker 测试发送两个固定样例候选。API 只返回成功状态或脱敏错误类别，不回传密钥和底层错误文本。

## 保存失败修复

- 原因：保存某个模型角色时，后端会尝试用其他已保存但尚未配置 API Key 的角色创建客户端，导致请求返回 422。
- 修复：构建运行时只启用已配置凭证的角色；其他角色的模型名与地址仍保留，待凭证配置后可单独启用。
- 回归验证：增加“已有无凭证的其他角色时，仍可单独保存当前角色”用例，API 单测共 60 passed。

## 使用说明

展开相应卡片，填写模型参数，先点“测试连接”确认当前草稿可用，再点“保存配置”。连接测试会产生一次真实模型请求，可能计入模型服务的调用量；Embedding 和 Reranker 的请求内容为固定短样例。
