# Audit 分页与 CSV 导出

## 实现范围

- Audit 查询 API 和 SQLite Store 支持按 100 条 offset 分页，排序包含时间与事件 ID，确保同一页边界顺序稳定。
- Audit 页面增加上一页/下一页，并在切换筛选条件时回到第一页。
- 新增 `GET /api/v1/observability/audit/export.csv`，使用 Trace ID 和时间筛选条件导出最多 1,000 条匹配事件。
- CSV 使用 UTF-8 BOM；对以 `=`, `+`, `-`, `@`, Tab 或回车开头的字段加单引号，避免电子表格将字段解释为公式。

## 验证

- 后端全量测试：303 项通过，0 项失败；1 条第三方 Authlib 弃用警告。
- 前端测试：15 个测试文件、59 项通过。
- MyPy 检查 81 个源文件通过；Ruff 检查通过。
- 前端类型检查、ESLint 和生产构建通过。

## 边界

- CSV 单次上限为 1,000 条；更多结果需要缩小时间范围后分批导出。
- 列表使用 offset 分页，持续写入期间跨页查看可能出现位置偏移；对本地管理页面的短时浏览适用。若需要长时间审计检索，可升级为基于最后一条事件键的游标分页。
