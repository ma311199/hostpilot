# MCP STDIO 与连接管理验证

## 实现范围

- 外部 MCP Server 支持本地 STDIO 子进程和 Streamable HTTP；内置 FastMCP 保持进程内连接。
- MCP 连接管理页面支持增删改、启停、连接状态与工具数展示，以及导入 `mcpServers` JSON。
- JSON 导入支持 STDIO `command`/`args`/`cwd` 和 HTTP `url`；含非空 `env` 或 `headers`、或 URL 中存在常见凭证参数的输入会在提交前拒绝，凭证通过单独表单提交。
- STDIO 命令参数作为独立参数传递；子进程权限、allowlist、环境变量和凭证生命周期按 [ADR-0016](../decisions/0016-local-stdio-mcp-servers.md) 执行。
- 更新 ADR、架构说明、路线和前端进度页，明确内置进程内与外部 STDIO/HTTP 的连接边界。
