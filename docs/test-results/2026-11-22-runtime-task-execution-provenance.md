# Plan 子任务历史执行摘要验证

## 范围

成功 Plan 子任务可保存受限执行来源信息，并在跨 Turn 缓存审批时展示：工具 ID、成功调用聚合次数、效果等级和确认决策。摘要不保存工具参数、工具输出、凭证、幂等键、补偿令牌或自由文本。旧 SQLite 记录摘要为空，前端显示“执行摘要不可用”。缺少工具效果元数据时按 `unknown` 展示。

缓存审批继续提供“复用并跳过”与“忽略并执行”两个选择。重新执行可能重复产生副作用，仍经过当前工具策略和确认门。

## 失败、原因与修复

- TDD 首轮持久化测试因 `PlanTaskExecutionSummary`/`PlanTaskToolUsage` 尚未定义而无法收集；新增数据契约、SQLite 可空迁移字段和安全序列化后通过。
- 生命周期回归因 `TaskRunHandle.complete()` 尚不接受摘要而失败；完成结果携带摘要后通过。
- WebSocket/API 回归因缓存审批请求没有执行摘要字段而失败；请求类型和显式 allowlist 序列化后通过。
- 首轮确认包装集成测试发现生产路径缺少 `dataclasses.replace` 导入；补充导入后测试通过。测试夹具初次运行还因自身漏导入 `replace` 失败，修复夹具后继续验证。
- 首轮质量检查发现两处 Python 行宽和多个 import 顺序问题、一处 mypy 将确认 Provider 推断为 `Any`，以及前端三条格式警告；调整格式与 Provider 类型后全部清零。
- 故障注入测试通过 SQLite trigger 使结果行插入失败，确认 TaskRun 完成状态和结果行一起回滚，没有留下“已完成但无摘要”的半状态。
- 独立审查发现通用工具元数据只区分“无副作用/可能有副作用”，却被摘要映射成“不可逆”；将摘要改为对未细分等级显示 `unknown`，同时保留既有安全执行策略。新增断言先观察到错误的 `irreversible`（RED），修正后复测通过（GREEN）。

## 边界

本地测试验证 SQLite 数据迁移、事务、Trace 白名单和 Vue 审批卡片行为，不证明工具声明的影响等级一定与外部系统真实行为一致。旧记录不会推断影响等级；用户仍需基于卡片内容决定复用或重新执行。
