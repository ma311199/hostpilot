# 工具能力与执行边界目录验证

## 实现

- 工具目录 API 现在逐项返回传输方式、信任等级、执行环境、运行位置、能力范围和 OS 沙箱状态；高影响工具继续显示是否需要逐次审批。
- `ToolDescriptor` 增加传输方式和能力说明元数据。内置文件工具说明工作区范围、danger-full-access 例外及 64 KiB 单文件上限；Python 工具说明固定 Linux 隔离限制。
- 动态 MCP 工具按 STDIO 或 Streamable HTTP 标明执行位置，并说明能力范围由 Server 定义；STDIO 明确与当前 OS 用户权限共享且无 OS 沙箱，HTTP 明确由远端执行。
- 工具目录页面将上述字段分区显示，并将“无 OS 沙箱”“远端执行”和“沙箱已就绪/不可用”明确区分。内置文件工具现标记为 Linux bubblewrap 隔离进程；未就绪时禁用。

## 验证结果

- 后端定向测试：89 项通过。
- 前端 Vitest：17 个文件、67 项通过。
- mypy：3 个修改后的源文件通过。
- Ruff、ESLint、Vue TypeScript 类型检查和 `git diff --check` 通过。

## 语义边界

目录显示用于说明注册元数据和执行位置，不授予工具权限，也不代替 ToolExecutor 的策略、参数校验和审批。当前内置文件工具的操作在 Linux OS 沙箱内执行，应用层校验用于限定每次挂载范围。
