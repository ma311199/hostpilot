## 覆盖范围

- DTO 拒绝额外字段，冻结实例，并校验路由与其专属字段的组合。
- BudgetContext 对预算达到上限和零调用额度的情况报告耗尽。
- RetrievalToolRequest 要求显式预算；Evidence 时间戳须含时区。
- SandboxPolicy 默认拒绝网络、文件系统和 capability；拒绝决策不能包含授权能力。
- Settings 从 HOSTPILOT_ 前缀读取环境配置并提供非敏感默认值。
- Trace、Cost、Audit 事件使用显式字段；生产日志以 JSON 结构输出。
