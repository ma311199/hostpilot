# Stage E：MCP 连接状态页面验证

- 日期：2026-11-07
- 范围：Vue 本地 Web 的 MCP 连接只读状态页及其 API 客户端
- 新增运行依赖：无

## 实现

- 新增 MCP 连接状态 API 客户端，读取 `GET /api/v1/mcp/connections`。
- 新增 MCP 连接页面并接入主导航，显示连接 ID、传输类型、最近连接状态、发现工具数量和脱敏错误类型。
- 页面支持手动刷新，并呈现首次加载、请求失败和无连接等状态。
- 页面不展示 endpoint、HTTP 请求头或凭证；连接配置和凭证继续由后端管理。
