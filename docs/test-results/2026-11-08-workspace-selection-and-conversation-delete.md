# 工作区目录选择与会话删除验证

## 实现范围

- 聊天侧栏显示当前工作区路径和只读状态，并可通过本机原生文件夹选择器切换工作区。后端以独立子进程打开 Tk 原生对话框，避免占用 API 事件循环；没有桌面会话或 Tk 支持时返回明确错误。
- 所选目录的规范化绝对路径存入本地 SQLite，应用重启后恢复。读取权限检查通过目录打开；写入权限检查创建并清理随机临时文件。
- 无法读取所选目录时返回权限错误并保留原工作区；可读不可写时设为只读。只读工作区的文件写操作在工具参数校验阶段拒绝，不弹出写入审批，也不提权或修改目录权限。
- 只读状态同步显示在聊天侧栏和 `/api/v1/tools` 目录中；不可用的两个文件写工具标为未配置并给出只读原因。
- 会话列表增加删除按钮和二次确认。删除调用现有 API，清理会话记录、LangGraph 检查点、会话摘要和待审批记忆提案；删除当前会话后打开最近剩余会话，否则回到空白聊天区。

## 验证结果

- 后端全量测试：316 项通过，0 项失败；1 条第三方 Authlib 弃用警告。
- 新增工作区权限检查、只读写入拒绝、SQLite 重启持久化、API 目录选择、只读降级和无读取权限时保留旧目录测试。
- 前端测试：64 项通过；覆盖目录状态/选择、只读标签、会话删除确认及删除后的会话切换。
- Ruff、MyPy（85 个源文件）、前端 TypeScript 检查和 ESLint 均通过。

## 已知边界

- API 自动化测试通过注入目录选择结果验证完整配置流程；未在当前测试环境弹出真实桌面窗口。真实 Tk 对话框需要在具有图形桌面会话的本机运行 API。
- 权限检查仅反映选择时应用进程的访问能力；目录权限后续变化时，文件操作仍会按实时系统权限失败并返回错误。
- Trace 与 Audit 记录按其各自保留策略保存，不随会话删除；会话正文、检查点、摘要和待审批提案会清理。
