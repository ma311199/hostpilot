# 模型配置弹窗文字拖选时误关闭

- 日期：2026-11-20
- 影响：模型配置弹窗；用户拖选模型名称时，若鼠标释放在弹窗外，浏览器可能将合成 click 事件落到遮罩层，触发弹窗关闭。
- 根因：遮罩层原先监听 `click.self`。它无法区分用户直接点击遮罩，还是从弹窗内部开始拖选文字后在遮罩上释放。
- 修复：改为监听遮罩层自身的 `pointerdown`。从弹窗输入框开始的拖选不触发遮罩按下事件；直接按下遮罩仍会关闭弹窗。

## 回归测试

- 新增组件测试覆盖：模型名称输入框开始指针操作、click 落在遮罩时不发送关闭事件；直接在遮罩上按下时仍发送关闭事件。
- 修复前定向测试确认误关闭：输入框开始、遮罩 click 后收到了 `close` 事件。遮罩按下关闭测试也按预期失败，因为修复尚未实现。
- 修复后前端 Vitest：**80 passed**（18 个测试文件）。
- ESLint、`pnpm typecheck`、`pnpm build`、`git diff --check` 均通过。

验证采用 Vue 组件事件测试，没有用真实浏览器做指针拖选端到端测试。
