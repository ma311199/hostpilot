# ADR-0001：Python 优先项目骨架

- 状态：已接受
- 日期：2026-10-28
- 更新日期：2026-10-29

## 背景

Agent 框架方向集中在 Python 生态，仓库已采用 Python src 布局，并配置 Python 3.11+ 与 uv。

## 决定

采用 Python 3.11+、uv 和 src 布局作为 HostPilot 的开发基线。此决定确定项目语言与依赖管理，不代表生产部署形态已确定。

## 影响

- 核心模块以领域契约隔离外部框架。
- 依赖通过 pyproject.toml 分组声明，并使用 uv.lock 固定解析结果。
- 若未来更改语言或包管理方式，需新增 ADR 并记录迁移影响。
