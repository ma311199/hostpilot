# ADR-0028：本地词项记忆召回与顺序回退

## 状态

已采纳

## 背景

MemoryController 首版按会话摘要优先、长期记忆其次的顺序填充字符预算。离线合成评测显示，本地 BM25 风格段落排序在固定预算下能改善相关片段的前排概率；词项匹配仍会漏掉同义改写。当前系统没有统一 Embedding Provider，也不应为了首轮召回排序引入向量数据库依赖。

## 决定

- 将会话摘要和长期记忆按 Markdown 标题／段落切成最多 1,200 字符的片段，并保留标题上下文。
- 使用无外部依赖的 BM25 风格词项评分对命中片段排序；中文以相邻双字词项参与匹配，英文按词项匹配。
- 按单次总字符预算依次注入词项命中片段，再按原顺序补入未命中的片段。原顺序为当前会话摘要优先、共享长期记忆其次；空查询仍被拒绝。
- 会话范围校验在候选生成前执行。其他会话的会话摘要不得进入候选、打分或结果。
- 不调用模型、不生成向量、不新增持久化索引或依赖；Trace 不记录查询或记忆正文。

## 影响

- 相关词项命中的段落可优先进入有限上下文；无匹配词项时退回原有顺序，尽量保留已有信息。
- BM25 风格评分只处理词项重合，不理解语义。同义表达仍可能无法排序到前面；顺序回退只降低漏召回风险，不解决上下文预算有限时的排序问题。
- 离线评测的词项排序结果是候选排序指标，并非本地混合召回的生产质量承诺。

## 复核条件

增加 Embedding Provider、引入用户认可的代表性记忆评测集、实测发现相关段落被截断或排序退化时，复核切块、评分和回退策略。向量索引只有在离线评测证明有额外收益且存储边界明确后再单独决策。
