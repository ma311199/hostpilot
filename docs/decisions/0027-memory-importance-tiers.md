# ADR-0027：记忆重要性评分与分层存储

## 状态

已采纳（首版启发式，待用真实样例校准）

## 背景

记忆写入原先只有统一审批和完整替换语义，无法区分临时信息与长期有用内容，也没有保留中等重要信息的简洁版本和原文之间的关系。评分和摘要不得为了判断价值而把记忆正文发送给模型。

## 决定

- 写入提案由本地确定性规则评估，返回 0–100 分、等级、非敏感原因码和（中分时）抽取式摘要。评分与摘要不调用模型。
- 0–39 分为低分：不进入审批队列、不写入记忆或原文归档，并记录不含正文的丢弃审计事件。
- 40–74 分为中分：仍需用户审批；批准后将最多 800 字符的抽取式摘要写入目标记忆，将原文和范围元数据写入受限 JSON 归档。
- 75–100 分为高分：仍需用户审批；批准后将原文写入目标记忆，不另建中分原文归档。
- 会话范围归档仅对对应会话列出；长期归档对各会话可见。审批仍只授权该次记忆写入，不授予工具权限。
- Markdown Store 最多保留 500 条原文归档，单条内容仍受记忆文件大小限制。达到归档上限时，中分提案写入失败并保留待处理状态，供用户处理；不会先写入摘要而丢失配对关系。
- 中分归档先写、摘要后写；若摘要写入失败，删除此次新归档，避免留下未配对原文。

## 影响

- 低分内容不会进入持久化记忆。中分内容在审批后同时保留摘要和原文，高分内容在审批后原样保存。
- 首版规则基于显式保存意图、偏好／约束词、内容长度、临时信息、运行日志、确认语和凭证样式模式；它是可解释的启发式，不具备语义理解能力。
- 凭证识别依赖模式匹配，不能保证识别所有秘密；调用方仍应避免提交凭证。评分规则可能误判，后续应基于经用户认可的正反例校准。

## 复核条件

收集到足够的匿名化或合成误判样例、增加记忆去重／合并策略、改变审批要求或归档生命周期时，复核阈值、规则、摘要方法和归档上限。任何规则调整应同时更新评分正反例测试。
