# ADR-0004：FastAPI 后端接口与前后端边界

- 状态：已接受
- 日期：2026-10-29

## 背景

HostPilot 当前仓库负责 Agent 后端能力，Web 前端由独立项目开发。后端需要明确对外 HTTP API 的实现框架和前后端职责边界。

## 决定

- HostPilot 后端对外 HTTP API 主要使用 FastAPI。
- Web 前端作为独立项目开发，通过明确、稳定的 API 请求 / 响应契约与后端对接；前端实现和依赖不纳入 HostPilot 仓库。
- FastAPI 属于接口适配层。领域逻辑和跨模块契约不依赖 FastAPI 专有类型。
- 当前版本前后端分别开发、部署在同一终端；用户通过本地 Web 界面操作，不需要登录。
- 当前面向单个本地用户，支持多个独立会话，各会话通过 conversation_id 隔离。
- 默认不接受来自其他终端的访问；远程访问不属于当前需求。
- Gradio 仅用于开发期原型，不作为正式 Web 前端。
- API 版本策略仍待后续决策；会话与记忆存储方案由 ADR-0005 确认。

## 后果

- API 模块实现时，将 FastAPI 登记为运行依赖并更新锁文件。
- API 请求和响应需映射到 HostPilot 应用服务及领域契约，不能把 HTTP 框架对象泄漏到核心业务模块。
- 相关 API 契约与后端行为由 HostPilot 仓库维护；前端项目依据这些契约独立开发与验证。
- 会话 API 必须显式携带或绑定 conversation_id，并确保上下文及预算状态不会跨会话混用。
